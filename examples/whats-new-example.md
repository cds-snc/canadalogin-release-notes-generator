## What's New

## August 30, 2026

### Migration App - TEST
`v1.12.14` deployed to Test on August 19, 2026
- We've made security improvements and updated supporting software to help keep the Migration App secure and reliable.
- We resolved some broken links that pointed to invalid help content pages.
- We've improved language selection when you choose "skip and create a new account" in the double sign-in flow.

### Manage App - TEST
`v1.30.0` deployed to Test on August 24, 2026
- We consolidated phone-number entry across the Manage App into a shared, accessible country-code picker and input, with clearer validation on the add-MFA-phone-number screen.
- We've improved OTP countdowns so the remaining time is based on when the code was created, reducing premature "code expired" messages.
- We've improved keyboard navigation so focus starts on the intended element when you move through the app.

### Sign-in, sign-up, recovery flows - TEST
- We've refreshed the sign-up flow with the latest GC Design System styling.
- Password recovery now presents the updated layout when MFA is not enabled.
- The Password Recovery Flow now routes users without MFA to the updated recovery page.
